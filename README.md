# Stochastic Modeling : Five Simulated Case Studies in Python 🎲

This repository contains a synthesis report and practical implementations completed for the **Modeling** course (2nd year) of the **Double Bachelor's Degree in Mathematics and Economics** at **Paris-Saclay University**.

It brings together five distinct practical works, each dedicated to a fundamental probabilistic model, analyzed from three angles :

**Mathematical construction** of the model.

**Numerical simulation** using Monte-Carlo methods.

**Comparison** of empirical results with theoretical asymptotic results (Law of Large Numbers, Central Limit Theorem, Extreme Value Theory, Criticality of branching processes, etc.).

## Repository Content

The repository covers five main themes :

### 1. Coin Flips
Exploration of probabilities and the Law of Large Numbers. Includes the Moivre-Laplace theorem, a mechanical illustration via the Galton board, and Poisson approximation for rare events.

### 2. Random Walks
Study of the fundamental building block of stochastic processes. Covers simple random walks on $\mathbb{Z}$, the gambler's ruin problem, and 2D and 3D random walks.

### 3. Coupon Collector
Analysis of the coupon collector's problem, focusing on cover time, the Gumbel distribution, and extreme value theory.

### 4. Population Genetics
Simulations of population dynamics using the Moran and Wright-Fisher models, observing genetic drift and allele fixation.

### 5. Branching Processes
Study of the Galton-Watson process, exploring generating functions and the criticality of branching processes.
